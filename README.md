# Absenteeism at Work - Machine Learning Evaluation

## Problem Statement

To analyze employee absenteeism patterns and empirically evaluate Linear Regression, Logistic Regression and Decision Tree Classification models.

## Dataset

Absenteeism at Work dataset.

## Machine Learning Models

### Regression
- Linear Regression

### Classification
- Logistic Regression
- Decision Tree Classifier

### Additional Model
- Random Forest Classifier

## Data Processing

- Data cleaning
- Duplicate removal
- Correlation analysis
- Correlation heatmap
- Feature engineering
- Train-test split
- Feature scaling

## Evaluation Metrics

### Linear Regression
- MAE
- MSE
- RMSE
- R² Score

### Classification
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Feature Engineering

Two additional features were created:
- Workload_Weight
- Age_Group

## Results

The models are empirically compared using appropriate evaluation metrics to determine their predictive performance.

- Pandas
